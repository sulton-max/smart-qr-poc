*Last updated: 2026-07-03*

### Content model — backend-owned encoding (2026-07-03)

Content is now one polymorphic `CodeContent` value object — domain VO = wire DTO (`[JsonPolymorphic]`, `type` discriminator) = `content_json` jsonb (EF `ValueConverter`). The **backend owns payload encoding** (`CodeContent.Encode()`; the 8 static encoders ported byte-for-byte from the old frontend `contentTypes.ts`), the payload is **derived not stored**, and the frontend sends typed fields with no local encoder — removing the frontend↔backend encoder-drift risk and giving real server-preview parity. Replaces the opaque `ContentSpec {type, fields, payload}`; migration `006-content-model`. Plan: `../../content-model-rewire.md`.

Green after the rewire: **Unit 107 · Integration 18 · E2E 68 · Migrations 10** · frontend typecheck + vitest 9.

### Iteration 1 — Static content types

- [ ] Ability to create a code from a static content type — URL, contact card (vCard), WiFi network, calendar event, location, email, SMS, and phone, plus plain text — each with its own builder form.

### Iteration 2 — Barcodes

- [ ] Ability to create non-QR symbologies (Code 128, EAN, UPC, Data Matrix, PDF417, Aztec) from the builder.

### Iteration 3 — Export and print

- [ ] Ability to download a code as an SVG or PNG file instead of opening it in a browser tab.
- [ ] Ability to get a print-ready code — vector output with a sufficient quiet zone, error-correction headroom, and sizing guidance — that stays valid as later decorations (logo, frames) are added.

### Iteration 4 — Builder correctness

- [ ] Ability to see clear validation and a guaranteed-unique short link when creating or editing a code.
- [ ] Ability to learn what each builder control does from an info popover by its header.
- [x] Ability to preview the exact server-rendered code in the builder so it matches the downloaded asset. *(server-preview parity for static content — the preview endpoint encodes the typed content with the same encoder as the saved asset; `CodePreviewTests.Preview_MatchesSavedImage_ForStaticContent`.)*
