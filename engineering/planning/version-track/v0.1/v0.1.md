# v0.1 — Product foundation

*Last updated: 2026-08-14*

**Status:** ✅ Complete · **Type:** Feature · **Started:** 2026-06-03 · **Completed:** 2026-06-18

### Iteration 1 — Code generation and serving

- [x] Ability to generate a QR code.
- [x] Ability to download a QR code as SVG and PNG.
- [x] Ability to route a scan to its destination with rules and a fallback.

### Iteration 2 — Guest identity

- [x] Ability to log in as a guest.
- [x] Ability to own codes that only you can manage.

### Iteration 3 — Code management

- [x] Ability to edit your codes.
- [x] Ability to search your codes.
- [x] Ability to enable and disable your codes.
- [x] Ability to delete your codes.
- [x] Ability to have edits take effect on the next scan.

### Iteration 4 — Verification

- [x] Create a QR code in the builder → it renders.
- [x] Download the code → SVG and PNG files.
- [x] Open the code by scan or short link → the destination.
- [x] Open a code with no rule match → the fallback.
- [x] Create a code as a fresh guest → it's yours.
- [x] Open it as another guest → not visible, not manageable.
- [x] Edit the destination → the next open resolves to the new one.
- [x] Disable a code → it stops resolving.
- [x] Enable it again → it resolves.
- [x] Search your codes → returns the matches.
