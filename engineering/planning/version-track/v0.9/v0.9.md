### Iteration 1 — Simulation background (drift · bump · mouse-chase)

- [x] `<HeroSim>` canvas behind the landing hero (`presentation/marketing/hero/`) — real, scannable QR "card" sprites baked from `qrcode`, wired into `LandingPage` with a scrim that keeps the headline legible.
- [x] Modes (**clash detection always on** → codes never overlap): **drift** (calm cruise + DVD-style wall bounce · **click pushes codes away** radially) · **bump** (angry — **weight-based ramming**, bigger size shoves smaller; roams **random waypoints** so no center-brawl; up to **⅓ randomly "rest"** (drop attacking → drift) for 2-3s then rejoin · **click = ~1s truce** then resumes) · **mouse-chase** (gather around the cursor with a dead-zone gap, packed not piled).
- [x] Perf: DPR capped **2 → 1.5** · **60fps** cap (40 looked blurry; also caps 120Hz→60) · **paused via `IntersectionObserver`** when the hero scrolls off-screen + on hidden tab (rect-guarded against flaky IO) · sprite count auto-reduces on narrow viewports. (Mobile: full responsive pass still deferred.)
- [x] Dev control bar (temporary) — mode dropdown + **mode-aware live sliders**: `drift`/`bump` = `count`·`speed`·`opacity` · `chase` = `count`·`speed`·`gap radius`. Dropped the code-spacing `gap` (codes pack with no artificial gap) + `bounce`. Params read per-frame via a ref; `count` reconciled without respawn.
- [x] Real codes: `hero/heroCodes.ts` `DAILY_THEME` — sprites encode today's theme (rickroll default) + a couple app links; daily update = one line.
- [x] Guardrails: `prefers-reduced-motion` → static scatter (no animation); pause on hidden tab; capped sprite count (26).
- [ ] Desktop-only for now — responsive pass deferred.
- [ ] Polish each mode with the sliders → bake the chosen values as defaults → **remove the whole dev bar** + add random-mode-per-refresh.
- [ ] v2 (from the concept): swarm / route / assemble modes · scannable Easter-egg codes · real ForeverPin dynamic short links (image fixed, destination rotates).
