## Escalate (behavior / bug / large-extraction — NOT polish → backlog or a version)

- `ShapeControls` — `FinderSwatch` dot-radius `frameRx*0.6` asymmetry: possible visual bug, verify intent.
- `ShapeControls` — eye column reuses one input for two things (your note): behavior bug.
- `FillControls` — `gradient.stops` used without a `length ≥ 2` guard: confirm the backend contract.
- `FillControls` / `EmojiControls` — emoji ↔ foreground-gradient z-order/blend on publish: possible visual conflict.
- `ContentTypeForm` — registry-driven content-type renderer (`def.renderer?()`): architectural unification, not polish.
- `contentTypes` — `buildContent` casts to `CodeContent`: confirm E2E covers the schema contract.
- **Large SDK extractions** (→ a version `Adoption`, not polish): module/finder selectable tiles, module swatch, `PresetGrid`, `Divider`, ColorPicker trigger-event.
