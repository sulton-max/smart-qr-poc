### Defects + drift (swept 2026-07-17)

> Found while analyzing Iter 13. All pre-date it; none block it. Ordered by severity.
> The trim is dropped, so these are **their own tasks** — none were fixed by trimming (the sweep already noted the 5→2 trim wouldn't fix the `Default` collision). D1+D2 both stem from one gap: **the builder offers routing that the submit path silently discards**. Fix them with M1, which reshapes the same surface.

- [ ] **Routing tab ungated for static types — silent rule loss.** `CreateCodeScreen.tsx:167` renders `RoutingView` for every content type; a user can author rules on a `wifi` code and save. `createCodeForm.ts:178` drops them at submit (`isStatic → routed = []`) and `superRefine` early-returns for non-`url` content (`:115`), so no error fires. Gate the tab on mode.
- [ ] **User-authored `Default` collides with the appended catch-all.** `RuleControls.tsx:69` renders `Object.values(RuleConditionType)` → `Default` ("Everyone else") is selectable. Submit appends a second (`createCodeForm.ts:194-197`) → two catch-alls on the wire. Prefill strips *all* Defaults (`:162`) → the user-authored one vanishes silently on re-edit. The strip/append pair assumes Default is never user-authored; the UI offers it. **The 5→2 trim keeps `Default` offered → does not fix this.**
- [ ] **`url` content has no server-side validation.** `ContentValidation.Apply` (`ContentValidation.cs:13-29`) passes `IsSupported()`, then `ContentTypes.Resolve(Url)` returns null (no `UrlContentSpec` registered — `ContentTypes.cs:14-17`) → no field check runs. `content = {type:"url", url:""}` with `rules: []` returns **200**.
- [ ] **E2E `Create_DynamicCode_WithEmptyFallback_StillReturns400` no longer tests its name** (`CodesCrudTests.cs:239-247`). Its 400 now comes from the empty *rule* destination, not a content check — `CodeRequests.Code(name, "")` (`HttpExtensions.cs:10-17`) emits both. Rename, or point it at a real `UrlContentSpec` once one exists.
- [ ] **`CodesListScreen.tsx:151-160` shows `shortUrl` + `CopyButton` for static codes**, where the short link is meaningless. `PreviewView.tsx:91,101` gates the same concept correctly with `isDynamicContent`.
- [ ] **Tick R6 — done, unticked.** `content` is already required (`CodeDto.ts:46`) and the legacy coalesce is gone from `createCodeForm.ts`; both landed under R3. Its line refs above are stale (`CodeDto.ts:49` → `:46`).
- [ ] **`isDynamicContent(null) → true` is vestigial** (`operations.ts:34`) — predates `CodeDto.content` going non-nullable. Both call sites pass non-null.
- [ ] **`RuleControls.tsx:22-24,37-39` copy still references "the fallback URL"** — R3 retired it; no-match is 404 now.
